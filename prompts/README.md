# Prompts y plantillas de texto

Archivos de apoyo para el proyecto **proyecto-n8n-hotel-ClaustroSF** (**ClaustroSF**), dominio **Hotel El Claustro de San Francisco**.

| Archivo | Uso |
|---------|-----|
| `prompt_asistente_hotelero.md` | Prompt base alineado al documento del hotel (referencia para n8n). |
| `prompt_cursor.md` | Pautas para usar Cursor en este repositorio sin romper entregables. |
| `prompt_kiro.md` | Especificación de alcance para herramientas tipo Kiro. |

Parte de la lógica sigue en el **Code Node** del workflow exportado (`workflows/asistente_hotel_basico_qwen.json`); mantenga coherencia entre estos archivos y ese JSON cuando actualicen el flujo en n8n.
