# Documentación del proyecto

Carpeta de documentación técnica del repositorio **proyecto-n8n-hotel-ClaustroSF** (**ClaustroSF**). Dominio del caso: **Hotel El Claustro de San Francisco**.

## Contenido

| Archivo | Propósito |
|---------|-----------|
| `pruebas_funcionales.md` | Casos y tablas: **PF-01 a PF-10** aprobadas (evidencia local); demás filas pueden seguir en **[PENDIENTE RTX]** hasta ejecutarse. |
| `arquitectura.md` | Vista de componentes Docker, n8n, Ollama y flujo de datos. |
| `explicacion_demo.md` | Guión breve para demostración en clase. |
| `plan_trabajo.md` | Fases del proyecto y trabajo futuro. |
| `riesgos_y_limitaciones.md` | Riesgos del modelo, límites del diseño actual y mitigaciones documentales. |

Las mejoras tipo AI Agent, Telegram, PDF, Google Docs o vector store se describen solo como **fases futuras**, no como funcionalidad entregada.
