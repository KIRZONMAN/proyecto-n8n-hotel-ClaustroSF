# Documentos de dominio (hotel)

Material de contexto para el **Hotel El Claustro de San Francisco** (repositorio **proyecto-n8n-hotel-ClaustroSF**, abreviatura **ClaustroSF**).

- `Documento_Base_Hotel.md` — información que debe respetar el asistente (habitaciones, políticas, horarios, servicios, etc.).
- `Preguntas_Prueba_Hotel.md` — lista de preguntas para ensayar manualmente en n8n.

Use Markdown para facilitar revisiones en Git. No incluya datos personales reales de huéspedes ni credenciales.
